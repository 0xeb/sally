Sally remains free, with every feature and update available to everyone.

- Choose the application icon colour in Options → Configuration → Main Window. Blue is available again; the updater follows your saved choice.
- The update confirmation is compact. Optional support actions appear when checking for updates and after updating; current supporters do not see the offer.
- The updater uses your custom panel font, or the Windows dialog font.
- Closing Sally cancels pending scheduled update work cleanly.
- Filename upper/lowercase formatting handles accented characters correctly.
- File Comparator applies pane orientation changes to the open comparison and adds toolbar buttons for word wrap and orientation.
