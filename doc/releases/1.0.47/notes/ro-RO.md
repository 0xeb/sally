- În fiecare panou se pot deschide mai multe file: Ctrl+Shift+T deschide o filă, Ctrl+Shift+W o închide, iar Ctrl+Tab și Ctrl+Shift+Tab (sau Alt+Shift+Right Arrow și Alt+Shift+Left Arrow) comută la fila următoare și la cea precedentă. Fiecare filă își păstrează propriul dosar, propria arhivă sau propriul sistem de fișiere al unui plugin (cum ar fi FTP), vizualizarea, ordinea de sortare, filtrul, selecția și istoricul, iar filele sunt redeschise la următoarea pornire. Filele pot fi redenumite, blocate, ordonate prin tragere și deschise prin plasarea dosarelor pe bara de file; din Configurare > Panouri se pot activa tastele Ctrl+T și Ctrl+W din Total Commander, iar din Configurare > Aparenta se poate stabili ca bara de file să fie afișată numai când un panou are două sau mai multe file (#72).
- Activați linia de comandă cu Ctrl+Shift+Down Arrow (apăsați din nou pentru a reveni): Ctrl+Tab, care făcea acest lucru înainte, comută acum între file.
- În dialogurile Arhivator și Dezarhivator sunt sugerate dosarele existente în timp ce tastați calea de destinație, iar în Copie, Muta și Schimba Directorul sunt sugerate dosarele unei arhive deschise într-un panou în timp ce tastați o cale în interiorul ei (#171).
- Meniul Editeaza se deschide fără întârziere. Anulare (meniul Editeaza sau Ctrl+Z) numește acum operația cu fișiere din Windows pe care ar anula-o și cere confirmare înainte de a o anula, deoarece Explorer folosește același istoric; când nu există nimic de anulat, Sally vă anunță (#172).
- Rezultatul unei actualizări manuale și întrebările acesteia sunt afișate complet cu orice font al panourilor, limitarea cererilor impusă de GitHub este numită explicit, împreună cu ora la care puteți încerca din nou, iar lista notelor de versiune este ascunsă când există o singură versiune de afișat (#170).
