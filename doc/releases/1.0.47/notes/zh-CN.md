- 每个面板可打开多个标签页：Ctrl+Shift+T 打开标签页，Ctrl+Shift+W 关闭标签页，Ctrl+Tab 和 Ctrl+Shift+Tab（或 Alt+Shift+右箭头 和 Alt+Shift+左箭头）切换到下一个和上一个标签页。每个标签页都保留各自的文件夹、压缩包或插件文件系统（如 FTP）、视图、排序顺序、过滤器、选定项和历史记录，下次启动时会重新打开这些标签页。标签页可以重命名、锁定、拖动排序，也可以通过将文件夹拖放到标签栏上来打开；可在“配置 > 面板”中启用 Total Commander 式的 Ctrl+T 和 Ctrl+W 快捷键，并可在“配置 > 外观”中设置仅当面板有两个或更多标签页时才显示标签栏（#72）。
- 使用 Ctrl+Shift+下箭头 激活命令行（再按一次返回）：以前用于此操作的 Ctrl+Tab 现在用于切换标签页。
- 在“打包”和“解压”对话框中输入目标路径时建议现有文件夹；在“复制”、“移动”和“改变目录”中输入某个面板中已打开的压缩包内部的路径时，建议该压缩包中的文件夹（#171）。
- “编辑”菜单现在会立即打开。“撤销”（“编辑”菜单或 Ctrl+Z）现在会显示将要撤销的 Windows 文件操作，并在撤销前请求确认，因为文件资源管理器共享同一历史记录；没有可撤销的操作时，Sally 会给出提示（#172）。
- 手动更新的结果及其提问在任何面板字体下都能完整显示；遇到 GitHub 请求限制时会明确说明，并给出可以重试的时间；只有一个版本可显示时隐藏发行说明列表（#170）。
