- Se pueden abrir varias pestañas en cada panel: Ctrl+Mays+T abre una pestaña, Ctrl+Mays+W la cierra, y Ctrl+Tab y Ctrl+Mays+Tab (o Alt+Mays+Flecha dcha y Alt+Mays+Flecha izda) cambian a la pestaña siguiente y a la anterior. Cada pestaña conserva su propia carpeta, archivo comprimido o sistema de archivos de plugin (como FTP), vista, orden, filtro, selección e historial, y las pestañas se restauran en el siguiente inicio. Las pestañas se pueden renombrar, bloquear, ordenar arrastrándolas y abrir soltando carpetas en la barra de pestañas; en Configuración > Paneles se pueden activar las teclas Ctrl+T y Ctrl+W de Total Commander, y en Configuración > Aspecto se puede hacer que la barra de pestañas solo se muestre cuando un panel tiene dos o más pestañas (#72).
- La línea de comandos se activa con Ctrl+Mays+Flecha abajo (pulse de nuevo esta combinación para volver): Ctrl+Tab, que antes lo hacía, ahora cambia de pestaña.
- Se sugieren carpetas existentes mientras se escribe una ruta de destino en los cuadros de diálogo Comprimir y Descomprimir, y las carpetas de un archivo comprimido abierto en un panel mientras se escribe una ruta dentro de él en Copiar, Trasladar y Cambiar directorio (#171).
- El menú Editar se abre sin demora. Deshacer (menú Editar o Ctrl+Z) ahora indica la operación de archivos de Windows que desharía y pregunta antes de deshacerla, porque el Explorador de archivos comparte ese historial; cuando no hay nada que deshacer, Sally lo indica (#172).
- El resultado y las preguntas de una actualización manual se muestran completos sea cual sea la fuente de los paneles; si GitHub limita las solicitudes, se indica ese límite y cuándo se puede volver a intentar, y la lista de notas de la versión se oculta cuando solo hay una versión que mostrar (#170).
