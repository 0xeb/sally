- Open several tabs in each panel: Ctrl+Shift+T opens a tab, Ctrl+Shift+W closes it, and Ctrl+Tab and Ctrl+Shift+Tab (or Alt+Shift+Right and Alt+Shift+Left) switch to the next and previous tab. Each tab keeps its own folder, archive or plugin file system (such as FTP), view, sort order, filter, selection and history, and the tabs come back at the next start. Tabs can be renamed, locked, dragged into order, and opened by dropping folders on the tab bar; Configuration > Panels can switch on Total Commander's Ctrl+T and Ctrl+W, and Configuration > Appearance can show the tab bar only when a panel has two or more tabs (#72).
- Activate the command line with Alt+Shift+Down (press it again to go back): Ctrl+Tab, which used to do this, now switches tabs.
- Suggest existing folders while you type a target path in the Pack and Unpack dialogs, and the folders inside an archive that is open in a panel while you type a path into it in Copy, Move and Change Directory (#171).
- Open the Edit menu without delay. Undo (Edit menu or Ctrl+Z) now names the Windows file operation it would undo and asks before undoing it, because File Explorer shares that history; when there is nothing to undo, Sally says so (#172).
- Show the whole outcome and questions of a manual update, whatever font the panels use, name GitHub's rate limit with the time to try again, and hide the release-notes list when there is only one release to show (#170).
