- Добавлен встроенный корейский язык для Sally, её модулей и программы обновления, а также онлайн-руководство на корейском языке (#167).
- На странице «Клавиатура» окна «Настройка» можно выбрать оболочку по умолчанию и до трёх дополнительных профилей оболочки с собственными сочетаниями клавиш; если удерживать Shift при выборе «Команды > Командная оболочка по умолчанию», оболочка по умолчанию откроется от имени администратора (#93).
- Команды меню пользователя можно показывать только там, где они полезны: правило «Показывать, только если» проверяет текущий файл и имя текущей папки и, если условие не выполняется, скрывает команду на панели меню пользователя и в меню пользователя F9 (#50).
- При копировании или перемещении одного файла предлагаются имена существующих файлов, а в диалоге «Создание папки» (F7) — существующие папки в качестве родительских (#51).
- Если модуль завершается сбоем при запуске, в отчёте о сбое указываются файл модуля, его последняя зарегистрированная версия и SDK.
- Окна, сообщения, модули и страницы руководства, где ещё оставалось название Salamander, теперь называют программу Sally.
- Надписи и флажки в окне «Настройка» подстраиваются под свой текст на всех языках и при системном шрифте Windows, поэтому больше не обрезаются.
- Выбранный язык сохраняется в виде стандартного языкового тега. После этого обновления при первом запуске Sally будет использовать язык интерфейса Windows или английский; при необходимости язык можно снова выбрать на странице «Язык» окна «Настройка».
