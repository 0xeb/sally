- Sally, 플러그인 및 업데이트 프로그램의 기본 제공 언어로 한국어를 추가했으며 한국어 온라인 설명서도 제공합니다(#167).
- 설정의 키보드 페이지에서 기본 셸과 최대 세 개의 추가 셸 프로필을 각각의 바로 가기 키와 함께 선택할 수 있습니다. Shift 키를 누른 채 명령 > 기본 셸을 선택하면 기본 셸이 관리자 권한으로 열립니다(#93).
- 사용자 메뉴 명령을 필요한 곳에서만 표시할 수 있습니다. "다음 경우에만 표시" 규칙은 포커스가 있는 파일과 현재 폴더 이름을 확인하며, 일치하지 않으면 사용자 메뉴 표시줄과 F9 사용자 메뉴에서 명령을 숨깁니다(#50).
- 단일 파일을 복사하거나 이동할 때 기존 파일 이름을 제안하고, 디렉터리 만들기(F7)에서는 기존 폴더를 상위 폴더로 제안합니다(#51).
- 플러그인이 시작 중에 실패하면 충돌 보고서에 플러그인 파일, 마지막으로 등록된 버전 및 SDK가 표시됩니다.
- 창, 메시지, 플러그인 및 설명서 페이지에 남아 있던 Salamander라는 이름을 Sally로 바꿨습니다.
- 설정의 레이블과 확인란이 모든 언어와 Windows 시스템 글꼴에서 텍스트에 맞게 조정되어 잘리지 않습니다.
- 선택한 언어를 표준 언어 태그로 저장합니다. 이 업데이트 후 처음 시작할 때 Sally는 Windows 표시 언어 또는 영어로 실행되며, 필요한 경우 설정 > 언어에서 언어를 다시 선택할 수 있습니다.
