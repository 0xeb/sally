Sally는 앞으로도 무료이며, 모든 기능과 업데이트를 누구나 이용할 수 있습니다.

- 디렉터리 줄에서 서버 또는 네트워크 루트를 클릭하면 이제 네트워크 보기가 열립니다. 공유 및 폴더 링크는 기존과 같이 탐색됩니다. (#155)
- **옵션 → 설정 → 일반 → 업데이트 확인**에서 **시작할 때마다**를 선택하면 실행할 때마다 즉시 백그라운드에서 업데이트를 확인합니다. 확인에 실패하면 다음 실행 시 다시 시도합니다. 기존 확인 간격 옵션은 이전과 동일하게 동작합니다. (#150)
- **테마**와 **아이콘 색**이 **모양** 페이지의 **응용 프로그램 모양** 그룹으로 통합되었습니다. 기존 아이콘 선택과 저장된 기본 설정은 그대로 유지됩니다. (#151)
