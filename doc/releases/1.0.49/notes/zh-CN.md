- 批量重命名的预览中只突出显示所选行，并且在浅色和深色模式下所有行都清晰可读（#175）。
- 插件列表在深色模式下显示深色列标题。
- 批量重命名在含有重音字母和非拉丁字母的名称中按正确位置截取。
- 批量重命名的“时间”和“日期”项插入在文件名中有效的格式。
- 批量重命名的“重置”不再开启“移除空目录”。
- 使用关闭按钮或 Alt+F4 关闭批量重命名时，会像按 Esc 一样请求确认。
- “剪切”、“复制”和“属性”可用于查找结果，且剪切或复制失败时不再更改剪贴板内容。
- 现在也可以通过 GitHub Sponsors 支持 Sally。
