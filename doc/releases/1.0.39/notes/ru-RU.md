Sally остаётся бесплатной. Все функции и обновления доступны каждому.

- Необязательные автономные ключи отмечают вашу поддержку.
- Окно обновления показывает переведённые заметки и сообщения разработчика.
- Справка → Что нового открывает заметки установленной версии без сети.
- Наш основной сайт теперь [get-sally.app](https://get-sally.app/).
- Выделенные файлы лучше видны в тёмной теме; пользовательские цвета сохраняются.
- Библиотека 7-Zip обновлена до 26.04, включая фильтры ARM64 и RISC-V.
- Для просмотра SVG доступны шахматный, светлый и тёмный фоны.
- Меню перетаскивания правой кнопкой объединяет файловые операции и расширения оболочки без второго меню.
- Сравнение файлов по умолчанию переносит строки, выравнивает обе панели и копирует исходный текст.
- При запуске с новым профилем заголовок с именем спонсора запрашивается только после инициализации настроек.
