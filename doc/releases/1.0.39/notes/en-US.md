Sally remains free, with every feature and update available to everyone.

- Optional offline supporter keys acknowledge your contribution.
- The update window shows localized release notes and maintainer messages.
- Help → What’s New opens the installed release notes offline.
- Our main website is now [get-sally.app](https://get-sally.app/).
- Selected files have clearer dark-theme colours; explicit custom colours are respected.
- The 7-Zip library is updated to 26.04, including ARM64 and RISC-V filters.
- SVG previews offer checkerboard, light and dark backgrounds.
- Right-drag menus combine native operations and registered shell extensions without a second menu.
- File Comparator wraps text by default, keeps both panes aligned and copies the original text.
- Fresh-profile startup no longer requests a supporter title before configuration is initialized.
