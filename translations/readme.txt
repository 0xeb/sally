Sally translation source archives
=================================

Each language directory contains the tracked .slt archives used to build Sally's
translated language packs.

Translation updates are welcome as pull requests. Modify only the relevant .slt
archives and describe the language and modules changed. The maintainer validates
the archives against the current resources and builds the shipping .slg files
before each release.

Generated Translator projects, translator.exe, language-pack build scripts, and
release packaging tools are maintainer infrastructure and are intentionally not
stored in this repository.
